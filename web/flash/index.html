Flash ESP-SDR to an ESP32

Connect the board over USB, click the button and choose its serial port. This writes the bootloader, partition table and application for the plain ESP32 chip (WROOM-32 / WROOM-32U). Existing flash content is replaced.

Web Serial is not supported in this browser. Use desktop Chrome, Edge or Opera. Web Serial needs HTTPS (or localhost).

Notes

  • WROOM-32 boards have no native USB. They need a USB-UART bridge (CP210x, CH340 or FTDI) and its driver on your computer.
  • If flashing fails to connect, hold the BOOT button while you press Install (and tap EN/RESET if needed), then release BOOT once writing starts.
  • After flashing, the board speaks the serial protocol at 2 Mbaud. Try the ELRS viewer.
